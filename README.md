# Exercícios JavaScript

Exercícios práticos baseados nos slides:

1. Operações aritméticas em tabela dinâmica.
2. Evento `mouseover` em imagem.
3. Contador com evento `change` em campo de seleção.
4. Bloqueio das teclas Q, W e X.
5. Calculadora com delegação de eventos.

## Como executar

Inicie um servidor local na pasta do projeto:

```powershell
python -m http.server 5500
```

Depois abra `http://localhost:5500`.
